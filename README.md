# 🛍️ Product Registration Form  

A simple **product registration web app** built to practice DOM manipulation, form handling, and frontend logic using **HTML, CSS, and JavaScript**.  
Este projeto faz parte dos meus estudos em **desenvolvimento web** e também será base para outro projeto de **automação com Python**.  


## 🚀 Features | Funcionalidades  

**EN**  
- Login page with basic credential validation  
- Product registration form  
- Form submission control using JavaScript  
- Dynamic data capture with arrays and loops  
- DOM manipulation for handling user input  

**PT-BR 🇧🇷**  
- Página de login com validação básica de credenciais  
- Formulário de cadastro de produtos  
- Controle de envio do formulário com JavaScript  
- Captura dinâmica dos dados usando arrays e loops  
- Manipulação do DOM para interação do usuário

## ⚙️ How It Works / Como Funciona  

**EN**  
1. The user logs into the system.  
2. JavaScript validates the credentials.  
3. After login, the user is redirected to the product registration page.  
4. The form collects product information.  
5. JavaScript captures and stores the data dynamically using DOM manipulation.  

**PT-BR**  
1. O usuário faz login no sistema.  
2. O JavaScript valida as credenciais.  
3. Após o login, o usuário é redirecionado para a página de cadastro.  
4. O formulário coleta as informações do produto.  
5. O JavaScript captura e armazena os dados dinamicamente usando manipulação do DOM.
